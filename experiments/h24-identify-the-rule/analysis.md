# H24 — the learned rule is uncertainty-AVERSE

## The fixed acquisition rule, signed

| feature | $\bar{w}$ |
|---|---|
| `mu_H` | **+1.0824** |
| `mu_L` | **+0.8254** |
| **`sigma_H`** | **−0.5487** |
| `dist_inc` | −0.2976 |
| `x[1]` | −0.4452 |
| `x[4]`, `x[2]`, `x[5]`, `x[0]` | −0.2237, −0.1771, −0.1261, −0.0995 |
| `x[3]` | +0.0717 |
| `sigma_L` | −0.0177 |

**The weight on `sigma_H` is negative.** The learned rule *penalises* posterior
uncertainty at the high-fidelity oracle. Every standard BO acquisition —
UCB, EI, MES — does the opposite, rewarding uncertainty because that is where
information lives.

So MF-DRO converges to approximately

    score(x) ≈ 1.08·mu_H(x) + 0.83·mu_L(x) − 0.55·sigma_H(x) − 0.30·dist_inc(x)

a **purely exploitative, actively uncertainty-avoiding** rule.

## The agreement sweep confirms the sign independently

| rule | agreement |
|---|---|
| `mu_L` alone | 9/12 = **75.0%** |
| `mu_H + mu_L` | 9/12 = **75.0%** |
| `mu_H` alone | 8/12 = 66.7% |
| `mu_H + 0.5·sigma_H` | 8/12 = 66.7% |
| `mu_H + 1·sigma_H` | 8/12 = 66.7% |
| MF-MES teacher | 8/12 = 66.7% |
| `mu_H + 2·sigma_H` | 6/12 = 50.0% |
| `mu_H + 3·sigma_H` | 5/12 = 41.7% |
| `mu_H + 5·sigma_H` | 3/12 = 25.0% |

Agreement **decreases monotonically as the exploration bonus grows**
(66.7 → 50.0 → 41.7 → 25.0%). That is an independent confirmation of the
negative `sigma_H` coefficient, and it does not depend on any single rule
matching.

## What we will and will not claim

**PRED 1 passes, but only just, and we do not name the rule.** The best match is
$75.0\%$ — exactly at the pre-registered bar — and *two* rules tie there on
$12$ pools. That is far too weak to say "MF-DRO is $\mu_L$". The coefficient
table and the monotone sweep are the robust results; the single best-matching
rule is not.

## Why this matters for the headline

This supplies the missing causal link between the mechanism and the performance
result. A rule that penalises HF uncertainty concentrates queries where the model
is *already confident*, which yields little new information and therefore slow
incumbent improvement — exactly the pathology this investigation began with.

MF-DRO does not merely fail to condition. **It converges to a fixed rule that is
anti-exploratory**, despite being trained on rollouts generated by an
information-seeking MF-MES teacher. The student inverted the sign of its
teacher's defining term.
